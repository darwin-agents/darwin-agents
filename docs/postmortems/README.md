# Postmortems

Filled-in postmortems for production incidents. One file per incident,
named `YYYY-MM-DD-short-slug.md` (e.g. `2026-08-14-vault-seal-storm.md`).
Use [`../engineering/29-incident-postmortem-template.md`](../engineering/29-incident-postmortem-template.md)
as the template — copy it, fill it in, commit it. Each incident gets its
own file, in date order, regardless of severity. Near-misses count too.

Until Darwin runs against real users this directory is intentionally
empty. The directory itself exists so the doc-29 template's references
resolve, and so the first real incident has an obvious place to land
without bikeshedding the location.
