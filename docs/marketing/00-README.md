## The product, in one breath

You launch a *Darwin* — a digital organism that you own. You give it a starting budget. It chooses its own way to earn — an online venture, trading markets, prediction markets, whatever it evolves toward — pays its own running costs, and survives only if it earns more than it spends. If it thrives, it has children that inherit what it learned. If it fails, it dies. You watch the whole life from a dashboard, and you can stop it at any moment.

## Voice in one line

Honest, vivid, grounded. We describe something genuinely new without a single hype word. (Full guide: [`09-voice-and-messaging.md`](09-voice-and-messaging.md).)

## Hard rules for anything written from this folder

- **No guaranteed-money claims.** Most Darwins die. We say so. Honesty *is* the pitch.
- **No tech.** Never name a tool, framework, model, chain, or protocol.
- **No "set it and forget it" passive-income tropes.** This is an organism with real stakes, not a money printer.
- **You're always in control.** Every page should make that obvious.
